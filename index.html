Math Games

A tiny playable fan site inspired by Ben Orlin's Math Games with Bad Drawings. This is an unofficial project for readers who want to try the games directly in a browser. Built with assistance from Codex.

Unofficial Fan Project

Math Games is made by a reader and is not an official Ben Orlin website. The games, framing, and playful spirit are inspired by Ben Orlin's book Math Games with Bad Drawings. The site was built with assistance from Codex.

Local First, Web Ready

Edit the files in this folder, refresh the browser, then sync the publish folder. New games can be added as plain HTML, CSS, and JavaScript files.
